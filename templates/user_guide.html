IngiTest_v1 is a professional web-based Test Management System built with Python Flask, Dynamic HTML and SQLite. This guide provides step-by-step instructions for administrators and users, some troubleshooting tips, and placeholders for screenshots.

1. Introduction

IngiTest_v1 is a comprehensive Test Management System for administering and taking tests within an office network. It features secure login, test configuration, question management, real-time progress tracking, and detailed results analysis.

5. Troubleshooting

Common Issues and Solutions:

- Database errors: Delete database schema and restart the app to reset.

- Timer issues: Ensure JavaScript is enabled and browser is compatible.

- Network access: Check firewall and IP configuration.

- Questions not displaying: Ensure questions are added via admin panel.

- For database or test summary issues, use the scripts in the tests/ folder as described in tests/README.md.

- Refer to app.py and tests/README.md for advanced troubleshooting, migration, and verification scripts.

- Clear Browser caches, if needed.

- If still facing issues, please reach out to Senthil Anand(336733).

6. Database & Technical Notes

Key SQLITE tables:

- TestSettings: Test configuration

- Users: User management

- UserAnswers: Question bank

- UsersTestResults: Test results

- UserTestSessions: Active test tracking

- UserResponses: User answer storage

- Database Schema is defined accordingly.
