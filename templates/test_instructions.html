Important Instructions

During the Test:
  • You can navigate between questions using Next/Previous buttons
  • Click on any answer option to select it
  • Use the "Save" button to save your current answers
  • Use the "Mark" button to flag questions for review
  • A timer will show your remaining time
Time Management:
  • The test will automatically submit when time expires
  • You can submit early using the Submit button on the last page
  • Your progress is automatically saved
  • Do not refresh or close the browser window
  • Take breaks only if absolutely necessary
